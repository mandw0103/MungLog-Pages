# TRPGLog — CCFOLIA 로그 → HTML 변환기

CCFOLIA 방의 채팅 로그를 **아바타·색·비밀(귓속말) 탭까지 포함**해 보기 좋은 HTML 로그로 변환합니다.
공식 "로그 출력"에는 아바타 이미지가 빠지고 비밀 메시지를 따로 다루기 어렵기 때문에,
로그인 세션에서 Firestore 데이터를 직접 받아오는 **수집기 + 변환 사이트** 2단계 구조로 만들었습니다.

```
[ccfolia 방 탭] 북마클릿/콘솔  ──postMessage──▶  [변환 사이트] index.html  →  보기 좋은 HTML 로그
   (collector 가 로그인 토큰으로 로그 수집)         (받은 JSON 을 바로 렌더링, 파일 불필요)
```

> 로그 수집은 **반드시 ccfolia.com 탭 안에서** 실행됩니다. 로그인 세션의 인증 토큰은
> 그 출처(origin)에만 있어, 변환 사이트가 직접 가져올 수 없기 때문입니다. 대신 수집한
> JSON 을 **postMessage 로 변환기 탭에 곧바로 넘겨** 파일 업로드 단계를 없앴습니다.

## 사용법

### 방법 A — 방에서 바로 가져오기 (추천, 콘솔·파일 불필요)
1. 변환 사이트에서 **"코코포리아 로그 가져오기"** 버튼을 **북마크바로 드래그**해 한 번 등록합니다.
2. CCFOLIA 에 **로그인**한 상태로 원하는 방(`https://ccfolia.com/rooms/...`)을 엽니다.
3. 등록한 북마크를 누릅니다. → 변환기가 새 탭으로 열리며 로그가 바로 들어갑니다.

### 방법 B — 콘솔 / 파일 (폴백)
1. ccfolia 방 페이지에서 `F12` → **Console** 에 [`collector.js`](collector.js) 를 붙여넣고 Enter.
2. 변환기로 자동 전달됩니다. 팝업 차단 등으로 막히면 `ccfolia-log-<roomId>.json` 이
   다운로드되니, 그 파일을 변환기에 끌어다 놓으세요.

### HTML 변환 (변환 사이트에서)
1. 로그가 들어오면 옵션을 고릅니다.
   - **채널 필터 · 시간 표시** — 출력할 탭과 시각 표기 여부.
   - **시크릿 다이스 숨기기** — 명령 앞에 `S` 가 붙은 판정(`S1D3`·`SCHOICE`·`Scc<=80` 등)의
     내용을 `Secret dice 🎲` 로 가립니다(아바타·이름은 그대로).
   - **이어 출력** — 특정 번째(또는 특정 대사) 다음부터 끝까지만 잘라 저장.
   - **출력 색상**(🎨 스타일) — 배경 · 메인 · 정보·기타 · 시간 · 시스템 색을 직접 지정.
     (**시스템** 은 스탯 변동·장식선 같은 system 타입 로그의 본문 색으로, ccfolia 화면과 같은
     회색 `#888888` 이 기본값입니다.)
     아랫줄은 판정 등급 색(왼쪽부터 대성공 → 대실패 순) — **대성공 · 대실패** 를 고르면
     성공 네 등급은 대성공 색에서, 실패 두 등급은 대실패 색에서 갈라져 한 단계씩 어두워지도록
     자동으로 채워집니다(색 계열은 그대로 유지). 사이 네 칸도 직접 눌러 따로 고를 수 있으며,
     양 끝을 다시 바꾸면 자동 계산값으로 덮어써집니다.
     적용한 색은 브라우저에 저장됩니다.
   - **스탠딩 OFF**(🎨 스타일) — 아바타가 있는 캐릭터 이름이 등장 순으로 나열됩니다.
     고른 캐릭터(여럿 가능)는 출력에서 아바타 이미지가 빠지며, 이름·본문 위치는 그대로입니다.
     방마다 이름이 다르므로 색과 달리 저장하지는 않습니다.
   - 🎨 스타일의 색·스탠딩은 **적용**을 눌러야 결과에 반영됩니다(긴 로그에서 하나 고를
     때마다 다시 그리지 않도록). **기본값**은 패널을 통째로 처음 상태(기본 색 · 스탠딩
     전부 ON)로 되돌리고 바로 적용합니다.
   - **컷인 삽입** — 로그 사이에 이미지를 끼워 넣습니다(ImgBB API 키 필요).
   - **순서 바꾸기** — 미리보기에서 로그·컷인을 드래그해 순서를 조정.
     로그를 눌러 여러 개 고르면(연해집니다) 그중 아무 핸들이나 끌어 한꺼번에 옮깁니다.
   - **로그 삭제**(🗑) — 미리보기에서 로그·컷인 우측 ✕ 를 눌러 한 줄씩 바로 제거.
   - **되돌리기**(↶) — 삭제·순서 바꾸기·컷인 추가/삭제를 한 단계씩 되짚습니다(최근 50단계).
2. **HTML 다운로드** 또는 **HTML 복사**.

## 데이터 구조 (messages 컬렉션)

| 필드 | 의미 |
|---|---|
| `name` / `color` | 발화자 이름 / 이름 색 |
| `iconUrl` | 아바타 이미지 URL (핫링크) |
| `text` | 본문 |
| `channel` / `channelName` | 탭 ID / 탭 이름 |
| `from` | 보낸 uid |
| `type` / `extend` / `edited` | 종류 / 부가데이터 / 수정 여부 |
| `createdAt` / `updatedAt` | 생성/수정 시각 |

> CCFOLIA 에는 귓속말 기능이 없으며, 비밀 대화는 별도의 비밀 채널(`channelName` 이 `비밀(...)`)로 이뤄집니다.
> 본인이 접근 권한을 가진 채널의 메시지만 수집됩니다.

## 주의

- **비공식 도구**입니다. 본인이 접근 권한을 가진 방의 로그에만 사용하세요.
- 아바타는 `storage.ccfolia-cdn.net` URL 을 **핫링크**합니다. 원본이 삭제되면 이미지가 깨질 수 있습니다.
- 수집된 JSON·HTML 에는 본문(개인 RP)이 포함되니 외부 공유에 주의하세요.
- 인증 토큰은 브라우저 안에서만 사용되며 어디로도 전송되지 않습니다.
