ImgBB API 키 설정

이미지를 넣으려면 무료 API 키가 필요합니다. 아래 순서로 발급받아 붙여넣으세요.

  1. imgbb.com 에서 무료 회원가입 / 로그인
  2. api.imgbb.com 접속 → Get API Key 클릭
  3. 발급된 키를 복사해 아래 칸에 붙여넣고 저장

키는 이 브라우저에만 저장되며, ImgBB 업로드에만 쓰니다.
